# Working together

Keep changes small and easy to review. Describe the problem, expected behaviour and checks performed. For a new data source, record its coverage, date, coordinate system, access method and required attribution in `docs/data-sources.md`.

Agree on the commit message with the repository owner before pushing. Keep credentials and private addresses out of commits and issue reports.
