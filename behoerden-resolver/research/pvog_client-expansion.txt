<h2 class="anchor anchorTargetStickyNavbar_ev3V" id=was-ist-eine-client-id>Was ist eine Client ID?<a href=#was-ist-eine-client-id class=hash-link aria-label="Direkter Link zur Was ist eine Client ID?" title="Direkter Link zur Was ist eine Client ID?" translate=no>​</a></h2>
<ul>
<li class=pvog-li><span class=pvog-li-content>Ein eindeutiger Client‑Identifier (UUID), der Ihre Anwendung gegenüber den PVOG REST‑APIs identifiziert.</span></li>
<li class=pvog-li><span class=pvog-li-content>Format: UUID v4, z.B. <code>d526c5db-75fc-4ee4-a727-218ed279701c</code>.</span></li>
</ul>
<h2 class="anchor anchorTargetStickyNavbar_ev3V" id=warum-wird-eine-client-id-benötigt>Warum wird eine Client ID benötigt?<a href=#warum-wird-eine-client-id-benötigt class=hash-link aria-label="Direkter Link zur Warum wird eine Client ID benötigt?" title="Direkter Link zur Warum wird eine Client ID benötigt?" translate=no>​</a></h2>
<ul>
<li class=pvog-li><span class=pvog-li-content>Identifikation Ihres Clients bei API‑Zugriffen.</span></li>
<li class=pvog-li><span class=pvog-li-content>Schnellere, zielgerichtetere Unterstützung durch den PVOG Support bei Problemen oder API‑Änderungen.</span></li>
<li class=pvog-li><span class=pvog-li-content>Bessere Möglichkeit zur Benachrichtigung und Betreuung der API‑Konsumenten bei wichtigen Änderungen.</span></li>
<li class=pvog-li><span class=pvog-li-content>Grundlage für zukünftige Verbesserungen und Anpassungen der Dienste.</span></li>
</ul>
